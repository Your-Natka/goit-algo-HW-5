# goit-algo-HW-5

Алгоритм аналізу ефективності пошуку підрядка
Крок 1. Підготовка даних

Завантажуємо два текстові файли: stattya1.txt, stattya2.txt.

Вибратємо підрядки для тестування:

Існуючий підрядок для кожного тексту (наприклад, "алгоритм" для статті 1, "структури даних" для статті 2).

Вигаданий підрядок для кожного тексту (наприклад, "неіснуючийпідрядок").

Крок 2. Реалізуємо алгоритми пошуку

Алгоритм Кнута-Морріса-Пратта (KMP)

Створити префікс-функцію (LPS).

Використовуємо її для пошуку всіх входжень підрядка.

Алгоритм Рабіна-Карпа

Обчислюємо хеш підрядка.

Порівнюємо хеші підрядків тексту з хешем шаблона.

Алгоритм Боєра-Мура

Створюємо таблицю зсувів за останньою появою символу.

Пошук підрядка з кінця підрядка для швидкого зсуву.

Крок 3. Вимірюємо часу виконання

Для кожного алгоритму та тексту:

Вимірюємо час пошуку існуючого підрядка.

Вимірюємо час пошуку вигаданого підрядка.

Використовуємо timeit для точного вимірювання:

import timeit

def measure_time(func, text, pattern, number=10):
    return timeit.timeit(lambda: func(text, pattern), number=number) / number

Крок 4. Збір результатів

Створюємо таблицю:
| Текст      | Підрядок   | KMP (с) | Rabin-Karp (с) | Boyer-Moore (с) |
|------------|------------|---------|----------------|-----------------|
| Стаття 1   | Існуючий   |         |                |                 |
| Стаття 1   | Неіснуючий |         |                |                 |
| Стаття 2   | Існуючий   |         |                |                 |
| Стаття 2   | Неіснуючий |         |                |                 |

Визначаєср найшвидший алгоритм для кожного підрядка.

Крок 5. Аналіз та висновки

Для кожного тексту вказуємо, який алгоритм найшвидший для існуючого та вигаданого підрядка.

Загальний висновок: який алгоритм ефективний в цілому.

Висновк (Markdown):

## Результати аналізу

### Стаття 1
- Існуючий підрядок: найшвидший — Boyer-Moore
- Неіснуючий підрядок: найшвидший — KMP

### Стаття 2
- Існуючий підрядок: найшвидший — Boyer-Moore
- Неіснуючий підрядок: найшвидший — Rabin-Karp

### Загальний висновок
Boyer-Moore ефективний для пошуку реально існуючих підрядків у великих текстах, KMP та Rabin-Karp краще справляються з перевіркою відсутніх підрядків.
